# 💚 ZenHeal — Healthcare Website

A **user interface design project** for a comprehensive healthcare website focused on accessibility, clean design, and patient-centric navigation.

---

## ✨ Features

- **Health Condition Pages** — detailed info on heart disease, glaucoma, and more
- **Wellness Guides** — healthy eating, hydration tips, immune system boosting
- **Guided Resources** — structured health guidance and stress management
- **Drug Information** — dynamically generated drug reference files
- **Responsive Design** — clean, accessible UI across devices

## 🛠️ Tech Stack

| Layer     | Tools                  |
| --------- | ---------------------- |
| Structure | HTML5                  |
| Styling   | CSS3                   |
| Logic     | JavaScript             |
| Assets    | WebP, JPEG, PNG images |

## 📂 Project Structure

```
ZenHeal-team11/
├── index.html              # Main landing page
├── index.js                # Core JavaScript logic
├── healthyeating.html      # Healthy eating guide
├── immunesystemboosting.html  # Immune system tips
├── heartdisease(h).html    # Heart disease info
├── glucoma(g).html         # Glaucoma info
├── h2o.html                # Hydration guide
├── guided.html             # Guided wellness resources
├── hbs.html, hst.html, gta.html  # Additional health pages
├── generat_drug_files.js   # Drug file generator script
└── *.webp, *.jpeg, *.png   # Medical & wellness imagery
```

## ▶️ How to Run

Simply open `index.html` in any modern browser — no build tools required.
